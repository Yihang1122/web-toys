# 专注冲刺 Focus Sprint

A Pomodoro-style focus timer that runs entirely in the browser — no build step, no dependencies.

## Running it

Open `index.html` directly in a browser:

```
open index.html
```

## Features

- 25-minute focus / 5-minute short break / 15-minute long break modes
- A countdown ring drawn on `<canvas>`
- A completion chime synthesized with the Web Audio API
- Streak and completion stats saved across sessions via `localStorage`
